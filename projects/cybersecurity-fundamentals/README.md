# Cybersecurity Fundamentals & Threat Landscape Analysis

## Overview

This project documents foundational cybersecurity learning completed through TryHackMe's Introduction to Cyber Security content.

The project focused on understanding the purpose of cybersecurity, common cyber threats, fundamental security principles, and how organisations protect systems and information.

## Objective

The objective was to develop a stronger foundation in cybersecurity and understand how common threats can affect individuals and organisations.

## Areas Covered

- Cybersecurity fundamentals
- Common cyber threats
- Phishing
- Malware
- Ransomware
- Social engineering
- Unauthorised access
- Confidentiality, Integrity and Availability (CIA)
- Basic defensive security concepts

## Risks Identified

Common organisational cybersecurity risks include:

- Credential theft through phishing
- Malware infections
- Ransomware attacks
- Social engineering
- Unauthorised system access
- Loss of confidentiality, integrity or availability

## Security Measures

Potential security measures explored included:

- Multi-factor authentication
- Security awareness training
- Access controls
- Principle of least privilege
- Software patching and updates
- Backups and recovery planning

## Skills Developed

- Cybersecurity fundamentals
- Threat identification
- Security awareness
- Basic cyber risk thinking
- Defensive security concepts

## Key Takeaway

Cybersecurity is not only about preventing technical attacks. Organisations must understand their threats, protect critical information and systems, manage human-related risks, and implement appropriate security controls.
